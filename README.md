A responsive and visually designed Empathy Map for a busy professional persona in a fitness app case study.

- Occupation: Software Engineer

- Empathy Map

- How Might We (HMW) Questions
- Responsive UI Design

### 💻 Technologies Used
- HTML5

- JavaScript

### 🎯 Objective
The purpose of this project is to understand user behaviour, emotions, frustrations, and motivations in order to design better user experiences.
